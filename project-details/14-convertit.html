Doc2Markdown Docs to Markdown

About the Project

Doc2Markdown turns everyday documents — PDF, Word, PowerPoint, Excel, CSV, TXT and HTML — into clean, editable Markdown in seconds. Server-side conversion keeps files private, and an instant preview lets you copy production-ready Markdown the moment your upload finishes.

Main Features

  • PDF, DOCX, PPTX & XLSX uploads
  • TXT, CSV, HTML & MD input support
  • Server-side conversion engine
  • Instant side-by-side preview
  • Conversion history tab
  • One-click copy-ready output
