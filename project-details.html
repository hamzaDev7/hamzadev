About the Project

A modern, feature-rich job portal connecting job seekers, students, and recruiters on one platform. JobCarrer lets users discover relevant opportunities and apply instantly — with real-time chat, AI-powered resume parsing, and an intuitive employer dashboard built for scale.

Main Features

  • AI-powered resume parsing & smart matching
  • Real-time recruiter–candidate chat
  • Advanced job search with smart filters
  • Employer analytics dashboard
  • One-click apply & application tracking
  • Fully responsive mobile-first design
